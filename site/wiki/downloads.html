What downloading needs

  • At least one source to search, from a source list you add. Sources covers it.
  • A torrent client, the qBittorrent that does the downloading. Anibeam brings its own, or uses one you already run.

Pick a torrent client

  1. Open SettingsDownloads.
  2. Under Torrent client, set Which client.
  • Built-in runs a qBittorrent of Anibeam's own, quietly in the background. Nothing to install and nothing to fill in. Only this computer can reach it. It keeps going after Anibeam quits, so new episodes still arrive.
  • My own uses a qBittorrent you run yourself, on this computer, another one or a seedbox.
  • Auto uses a qBittorrent that answers at the address you give, and runs the built-in one when none does.

Use your own qBittorrent

  1. In qBittorrent, open ToolsOptionsWeb UI.
  2. Tick Web User Interface (Remote control), and set a username and a password.
  3. In Anibeam, set Which client to My own.
  4. Fill in Address with the Web UI's address, such as http://localhost:8080, then Username and Password.
  5. Press Save and test. It says which qBittorrent version answered.

The password goes in your system's password store. Saved clients keeps more than one, such as a seedbox and the one on this computer; the client chip on the Downloads page switches between them.

Where downloads go

The built-in client saves into your library folder, each show in a folder of its own, so a finished episode shows up in the library by itself. A show already in the library downloads into its own folder, and films go into a Movies folder.

  1. Open SettingsDownloads. Save to shows the folder in use.
  2. Press Choose folder and pick another one. New downloads go there at once.
  3. Reset goes back to the library folder.

Your own qBittorrent saves where it is told to. Make sure that folder is inside a folder Anibeam reads, or add it in SettingsLibrary. An episode saved anywhere else downloads fine and never reaches the library.

Get episodes of a show

  1. Open the show, from the Library, Airing or a search, and press Get episodes.
  2. Pick the episodes you want. Episodes already on disk are left out unless you turn on replacing them.
  3. Press the button that counts them, such as Get 12 episodes.

To find a release by name instead, open the Downloads page and type into Search for a show, or a release name. Pick the show, then press Show releases next to a source under Found on to see what it found. Tick the releases you want and press Download.

Follow a show as it airs

  1. On Get episodes, turn on Subscribe for new episodes, or press Subscribe after a search on Downloads.
  2. Each new episode downloads as it comes out, into the same folder.

Following on the Downloads page lists every show you follow. Unsubscribe stops one. A show is dropped by itself 16 days after its last episode airs, while Unsubscribe from finished shows is on.

Long shows and disk space

A long show downloads a few episodes at a time, and each one you finish starts the next. Set it under Rolling downloads in SettingsDownloads: how many episodes stay ahead, what counts as long, and whether watched episodes are deleted or kept.

Gaps in your library on the Downloads page lists aired episodes that are not on disk. Downloaded lists what is on disk, the biggest first, with Delete watched to free space. Deleted files go to the trash.
