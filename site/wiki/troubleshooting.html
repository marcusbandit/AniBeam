See what went wrong

The line along the bottom of the window shows the last thing Anibeam did. Click it to open Activity, and pick Problems to see only what failed. Click a line to copy it.

The library stays empty

  • Check that you added the folder above your shows, not a show's own folder. SettingsLibrary lists what Anibeam reads.
  • Each show needs a folder of its own with video files in it. Name folders and files has an example.
  • A folder that says Unavailable is on a drive Anibeam cannot reach. Plug it in and press Rescan.

A show is not recognised, or has the wrong poster

Anibeam looks a show up by its folder name. Extra words, a typo or a name in another language can miss. Open the show, press Fixes and pick the right one. Your library has the steps.

Episodes are missing, doubled or in the wrong order

A file name without a clear episode number reads wrong. Open the show, press Fixes, then Files, and say what each file is. Your library has the steps.

A show with more files than episodes says so under Extra files: misnamed files, duplicates or specials.

A search finds nothing

  • No sources to search yet on the Downloads page means no source is on. Paste a source list's address right under it and press Add: Sources has the steps.
  • All sources are turned off means each one is off. Press a source under Sources on the Downloads page to turn it on.
  • A source that asks for a key and has none shows what it needs. Press Add its value next to it in SettingsDownloads.
  • No releases for a title can mean the source spells it another way. Try fewer words, or the title in romaji.

The torrent client is not connected

  • With your own qBittorrent: check it is running and its Web UI is on, then press Test in SettingsDownloads. Details shows what qBittorrent answered.
  • A wrong address or password says so after the test. Fix it and press Save and test.
  • To stop running your own, set Which client to Built-in.

Downloads could not start

Searching runs through a small helper program that Anibeam starts itself. When it stops, the Downloads page says so: press Start again. When Settings point at a helper of your own that does not answer, Use Anibeam's own switches back.

A download finished and is not in the library

It saved into a folder Anibeam does not read. Where downloads go explains how to line the two up. Once the folder is in SettingsLibrary, the episode shows up on the next scan.

The AniList or MyAnimeList sign-in did not finish

  • The redirect address on AniList or MyAnimeList must match Anibeam's exactly. Press Copy the address again and paste it over the old one.
  • The Client ID must be the one from the same app.
  • Press Open the sign-in page again and approve Anibeam in the browser.

A room will not open

No room has that code
Check the code with whoever sent it. The room may have closed.

A room takes 10 people.
That room runs on a newer version of rooms
Update Anibeam from SettingsAbout.
Could not reach the room server
Check your connection, and that Room server in SettingsPlayback was not changed by mistake.

Where your data is

Your library, history and settings stay on your computer. Type files into the search field in Settings: Where Anibeam keeps its files shows the folder. Back up the library, found the same way, saves everything to one file that restores on another computer.

Report a problem

  1. In Settings, press Report a problem.
  2. A bug report opens on GitHub in your browser, with your version filled in. Say what you did and what happened. A screenshot helps a lot.

For a show that reads wrong, File an issue on GitHub in its file fixes fills in the show and its file names. The issue is public, and you see everything in it before you send it.
